# 1C MCP — доработка расширения для произвольных запросов (custom_query)

[![GitHub](https://img.shields.io/badge/GitHub-Repository-black)](https://github.com/abask-grodno/1c_mcp_custom_query)
[![Original Project](https://img.shields.io/badge/Original-1C_MCP-blue)](https://github.com/vladimir-kharin/1c_mcp)

> **Расширение** для MCP-сервера 1С от [Vladimir Kharin](https://github.com/vladimir-kharin), добавляющее новый инструмент `custom_query` — выполнение **произвольного запроса на встроенном языке 1С**.

Оригинальный проект `1c_mcp` реализует MCP-сервер для 1С, но не включает возможность выполнять произвольные запросы к базе данных. Я добавил эту функциональность в виде отдельного расширения конфигурации.

## 🔧 Что добавлено

- **Инструмент MCP:** `custom_query`
- **Параметр:** текст запроса на языке 1С (например, `"ВЫБРАТЬ ... ИЗ ..."`)
- **Результат:** данные, возвращённые запросом, в удобном для MCP формате

## 🎯 Зачем это нужно

С помощью `custom_query` вы можете:

- Создавать **Telegram-ботов** (как сделал я), которые напрямую обращаются к 1С.
- Давать LLM-ассистентам возможность выполнять аналитические запросы к вашим данным в реальном времени.
- Тестировать и отлаживать запросы 1С удалённо через MCP-клиенты.
- Интегрировать 1С с любыми AI-системами, поддерживающими MCP.

## 🚀 Установка и использование

### 1. Установите оригинальный MCP-сервер

Следуйте инструкции из [README оригинала](https://github.com/vladimir-kharin/1c_mcp). Убедитесь, что сервер запускается и базовые инструменты работают.

### 2. Добавьте расширение `MCP_Сервер_произвольный_запрос.cfe`

- Скопируйте файл `.cfe` из этого репозитория на компьютер с 1С.
- Откройте конфигуратор 1С → ваша конфигурация → **Поддержка** → **Расширения**.
- Нажмите **Добавить** → выберите **Загрузить расширение из файла** → укажите `MCP_Сервер_произвольный_запрос.cfe`.
- Установите флаг **Безопасный режим** (снимите при необходимости) и настройте права.
- Обновите конфигурацию базы данных (меню **Конфигурация → Обновить конфигурацию базы данных**).

После этого расширение будет активно, и оригинальный MCP-сервер автоматически обнаружит новый инструмент `custom_query`.

### 3. Используйте инструмент `custom_query`

Вызвать его можно через любой MCP-клиент (например, Claude Desktop, Telegram-бота, скрипт на Python).

**Формат вызова (JSON-RPC):**

```json
{
  "method": "custom_query",
  "params": {
    "text": "ВЫБРАТЬ Номенклатура.Наименование, Номенклатура.Код ИЗ Справочник.Номенклатура ГДЕ Номенклатура.ПометкаУдаления = ЛОЖЬ"
  }
}

Пример ответа (упрощённо):

```json
{
  "result": [
    ["Наименование1", "00001"],
    ["Наименование2", "00002"]
  ]
}

🤖 Пример: телеграм-бот
Я использовал это расширение, чтобы сделать Telegram-бота, который понимает запросы на естественном языке и выполняет нужные запросы к 1С.

Пользователь пишет: «Покажи остатки по товару "Стул"»
Бот формирует запрос:
ВЫБРАТЬ Остатки.Количество ИЗ РегистрНакопления.ОстаткиТоваров ГДЕ Товар.Наименование = "Стул"
→ вызывает custom_query → отправляет результат.

🛡️ Безопасность
Инструмент custom_query выполняет произвольный код на языке 1С, что может быть опасно при неконтролируемом доступе.

Рекомендации:

Ограничьте доступ к MCP-серверу (только локальный хост или VPN).

При необходимости модифицируйте расширение, добавив проверку: разрешать только SELECT или только определённые таблицы.

Используйте отдельную базу данных для экспериментов.
